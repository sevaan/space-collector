Space Collector playtest

21 October 2026 · Local source v0.1.924, including the previous card fact audit. Browser testing used an isolated localhost origin with a disposable collection. Personal collection data was untouched.

Fixed

  1. Earned-card links opened the full field guide. Browsing an album, returning to Explore, collecting the Moon, then choosing “View in collection” produced “4859 / 4,860” and returned to Albums. Earned-card deep links now explicitly select Mine, clearing leftover filters.
  2. Find reused predictions from the wrong location. A Toronto ISS result remained after manually changing to Sydney. Predictions now carry a context including location, sky darkness, binocular mode and a ten-minute time window. Opening Collection clears mismatched caches; old worker responses are ignored and the worker is replaced when its context changes. Suggestions exclude plans from other locations or conditions and carry the same context.
  3. Tonight’s total disagreed with its rarity chart. The headline displayed 36 new cards while the chart contained 167 Common and 36 Uncommon cards. The total now includes all new cards; recommendations still prioritize the more interesting catches.
  4. A cleared city search could repopulate stale results. An in-flight location response remained valid until a subsequent request actually started. Every input change now invalidates earlier work immediately and clears old results. A controlled asynchronous regression test verifies clearing the field while a request is pending.

Verification

All 66 Node tests pass (62 existing, 4 new handler/worker regressions). JavaScript syntax checks pass for all changed modules. Browser console checks during the walkthrough found no captured errors or warnings. Tests use lightweight DOM and worker doubles to exercise actual handler code; they do not replace physical-device testing.

The local QA copy temporarily bypassed its own service worker after baseline testing so edited modules could reload. That QA-only worker is excluded from the project changes. Production cache versioning is unchanged.
