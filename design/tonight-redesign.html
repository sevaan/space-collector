Tonight, redesigned

The Tonight page answers one question: what should I go outside and catch, and when? Today it answers it four times in four different row styles across 4.7 screens. The redesign shows each pass once, puts everything that pass earns (new card, XP, shiny chance, mission, week theme, level up) on that pass, and folds the haul, the Dark chip, the Every-pass chart and the jump chips into one night strip at the top. Same look: navy, cream, burnt orange, Russo One and Barlow Condensed, the real mini cards.

Recommended

A · Night, top of the page
Night strip replaces the jump chips, haul card, “Dark 6:40 PM” and the Every pass chart: one sentence and the whole night at a glance (best window in orange, the headliner’s star, now). One hero (“headliner” said once, time said once). Up now is one row of chips, not two lists and a full Saturn card. The Plus banner is gone from the top.
A · Night, scrolled
Tonight’s run is the only list. Coming up = its first rows (the next one is lit), shiny chances and missions are pills on the passes that deliver them, the headliner is a one-line pin. Missions say where to do them. The whole page is about 2.5 screens in this 320 px frame, under 2 on a real phone (was 4.7). Plus is asked for once, where the bells are.
A · Night, end of the page
Missions say where. “Catch a rocket stage → 8:40 PM Thorad Agena D, south”. The week theme and Saturday’s event are one line each here, not cards that split the plan. The page ends with one row to all 327 passes (the chart already lives in the night strip).
B · Daytime
By day nothing is “coming up” for 4 hours, so the hero is dark in 4 h 10 min with the free until-dark reminder. Tonight’s headliner is previewed small (no countdown that reads “5 h 12 min”). The run starts with the evening’s first good pass; the Sun is the only thing “up now”, with the one true safety line.
C · Cloudy night
Today the hero still counts down “20 min 44 s · Show me” under “Overcast all night”. Here the weather is the hero: next clear night with the free reminder for it. The run is kept but collapsed and greyed (“if you spot a gap, these count”). Something true to learn while you wait: why cloud hides satellites without stopping them.
D · Almost nothing up (2:30 AM)
A quiet gap is normal and has a true reason (the low satellites overhead are in Earth’s shadow). Say it, give the time it wakes up, and offer what is worth doing now: planets you can see again for a level, the Moon’s new phase. No stale “Dark 6:40 PM”, no all-night “200 new cards”.
E · Bolder: the run as a deck
The same content as A, but tonight’s run is a hand of real cards you swipe through in time order; the night strip above scrubs it. It leans on what the game already does best (the cards) and makes “what will I get” literal. Costs more to build and hides the list; a good option if A tests flat.

What changes, in one list

Removed: jump chips; Plus banner at the top; Coming up as its own list; Shiny chances as its own list; the haul card; the separate Every pass chart; Seen before as full cards; the big SET REMINDERS button.
Merged: haul + Dark + Every pass chart → night strip (tap it for all passes). Coming up + run + shiny chances → one run, next pass lit. Missions, week theme and level-ups → pills on the passes, and missions say where.
Kept: the hero with the real mini card and countdown, XP everywhere, the rarity colours and shapes, Show me and the bell (ISS bells marked free, others dimmed), All passes.
States: day, cloudy and quiet each get their own hero; the run never pretends.
Build order if you like A: (1) one run with pills and the lit next row, drop Coming up and Shiny lists; (2) night strip, drop haul/Every pass card/chips; (3) state heroes for cloudy, day, quiet; (4) missions with “where”.
