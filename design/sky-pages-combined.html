Set reminders
  • Tonight's haul: the reason to go out. New cards (with a tiny rarity chart), missions it would finish, XP, and the weather window in one line.
  • The run: 3 to 6 stops chosen for you (the rarest new cards, shiny chances, stations), plus moments like dark, busiest and cloud. Each stop says what it gets you.
  • Each stop has its own target and bell: the target takes you to where to look in the sky, the bell sets a reminder for that one stop.
  • Plus one button for all of them: one each before the stops. Free players pick one stop; Plus gets the whole run. This replaces the hidden swipe.
  • Dawn ISS: shown at the end as "Early riser", never lost.
  • Full list: stays one tap away ("Everything tonight"), with Commons collapsed.

What it would take to build

  • Now: small. It reuses the "best upcoming" picker from today and the steering we already have. The countdown ring and the turning arrow are new.
  • Tonight's run and haul: medium. It picks stops from the plan we already compute, and checks which missions each stop would finish. "Set reminders" sets several reminders (one for free players).
  • Week strip, "Only this week" and the goal ring: medium. We already have every night's passes. "Only this week" compares how often each rare card passes; the Moon phase is already in the planner.
  • Everything else on the current tabs stays reachable: the full Tonight list, Also up tonight, the sky map and shiny chances.
